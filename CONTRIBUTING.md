# Contributing to Motech Audit Security Skills

Thanks for helping Ethereum developers build safer contracts.

## Propose a change
1. Open an issue describing the skill or improvement.
2. Fork the repository and make a focused change.
3. Keep each skill in `skills/<skill-name>/SKILL.md` with `name` and `description` frontmatter.
4. Run `python3 scripts/validate_skills.py` and include an example showing how the skill helps.
5. Submit a pull request explaining limitations and how you verified the change.

Do not submit proprietary code, customer audit material, private keys, or undisclosed vulnerabilities in deployed projects. Do not claim unverified findings are confirmed.
