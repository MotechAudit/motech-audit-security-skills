# Motech Audit Security Skills v0.1.0

**Initial public release — educational security review workflows and reproducible Solidity examples.**

## Included

- Agent-readable Solidity security review instructions in `skills/solidity-security-review/SKILL.md`.
- Reentrancy vulnerability and checks-effects-interactions mitigation examples.
- Missing access-control vulnerability and owner-restricted mitigation examples.
- Foundry regression tests for both examples.
- Python skill-structure validator and GitHub Actions CI.
- MIT license, contribution guidelines, and responsible disclosure guidance.

## Getting started

```bash
git clone https://github.com/MotechAudit/motech-audit-security-skills.git
cd motech-audit-security-skills
forge test -vv
python3 scripts/validate_skills.py
```

See [README](../README.md) for the review workflow and limitations.

## Scope and limitations

This is an early-stage open-source educational project. Vulnerable contracts must not be deployed with real funds. Agent-assisted findings require independent validation; the project is not a replacement for a professional manual audit. Motech Audit does not claim affiliation with or endorsement by Ethereum.org or the Ethereum Foundation.
