# Motech Audit Security Skills v0.2.0 — Release Draft

**Status: Draft only. Do not treat this file as a published release or as proof of a release tag.**

## Proposed scope

This draft is for a subsequent release after review and merge of the current quality-gate work.

### Added since v0.1.0

- A focused Solidity Vulnerability Detection Skill with hypothesis generation, attack-path tracing, evidence labels, and a structured output contract.
- A maximum-supply input-validation example with vulnerable and mitigated fixtures plus Foundry tests.
- A topic map connecting Security Skills workflows to the separate Motech Solidity Security Lab.
- Automated validation of Skill-local Markdown references, alongside existing metadata and layout checks.

### Quality checks

The repository workflow runs Python unit tests for the validator and validates published Skill metadata and local links. Foundry tests remain a separate workflow for the educational Solidity fixtures.

### Important limitations

- The Skills are agent instructions, not a standalone static analyzer or automated audit service.
- The Lab is a separate repository. Installing a Skill does not run Lab tests automatically.
- A passing fixture or metadata test does not prove a different smart contract secure.
- No broad model/editor compatibility matrix or independent adoption claim is included in this draft.
